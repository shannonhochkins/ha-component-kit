# useHistory()

###### `useHistory(entityId: EntityName, options: HistoryOptions)`

This hook is designed to retrieve the current history information from the entitiy if available.

> <b>NOTE:</b> This hook is already connected to the useEntity hook and returned as part of the entity object so you may never need to use
> this directly.

This will automatically subscribe/unsubscribe for you so there's no need to manage anything.

### Returned Value

<ArgTypes of={DummyComponentHistoryReturn} />

`error` contains the native subscription failure, or null after successful recovery. Handle it separately from an empty recording. A new connection or changed entity/options clears previous results and errors. Disabled subscriptions return no history; unknown or excluded Recorder data is not evidence that an event did not happen. The hook releases late-opening subscriptions on unmount.
